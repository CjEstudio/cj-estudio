CJ ESTUDIO — GitHub + Cloudflare Pages + Pages CMS

ARCHIVOS IMPORTANTES
- index.html: estructura visual
- assets/css/styles.css: diseño
- assets/js/app.js: funciones y carga del contenido
- data/site.json: teléfono, WhatsApp, correo, redes y textos
- data/services.json: servicios
- data/projects.json: portafolio
- media/: imágenes, logo y favicon
- .pages.yml: configuración del panel Pages CMS

CUANDO PAGES CMS ESTÉ CONECTADO
- Información general: teléfono, WhatsApp, correo, redes, textos, logo e imagen principal.
- Servicios: agregar, quitar y editar servicios.
- Portafolio: agregar proyectos, categorías, descripciones e imágenes.

No necesitas editar index.html para el trabajo diario.
